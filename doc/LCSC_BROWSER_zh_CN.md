# 立创元件桥：安装与使用

立创元件桥（LCSC KiCad Bridge）在 KiCad 中提供立创商城浏览窗口。商品列表「加入购物车」右侧显示 **「导入」**，详情页右下角显示 **「导入 KiCad」**；点击后，将该商品可用的符号、封装和 3D 模型下载并安装到当前工程。

## 运行环境

- KiCad **10.0 或更新版本**，启用插件 API。
- Windows 的内置网页需要 Microsoft Edge WebView2 Runtime。
- 插件的 Python 环境需要 wxPython（含 `wx.html2`）和 `kicad-python`。
- Windows 请在插件设置中选择 **KiCad 安装目录内的 `bin/pythonw.exe`**，例如 `D:\KiCad\bin\pythonw.exe`。插件使用随 KiCad 提供的 wxPython 和网页组件，不通过 pip 替换它们；普通系统 Python 不一定包含这些组件。
- `kicad-python` 由插件运行环境根据 `requirements.txt` 安装；非 Windows 环境还会通过该文件安装 wxPython。
- 首次准备 Python 环境及下载器件需要网络连接。

当前主要面向 Windows。macOS 和 Linux 的网页后端与运行环境仍需单独验证。

## 安装与升级

1. 在 KiCad 工程管理器中打开「插件和内容管理器」。
2. 点击「从文件安装」，选择 `LCSC-KiCad-Bridge.zip` 并完成安装。
3. 在 KiCad 首选项的插件设置中启用插件 API，并按提示准备插件 Python 环境。
4. 重新打开原理图或 PCB 编辑器，等待首次插件环境准备完成，在工具栏中找到绿色的「立创元件桥」按钮。已打开的编辑器可使用「工具 → 刷新插件」。插件从编辑器工具栏启动，工程管理器中的安装列表用于管理安装包。

插件包标识为 `com.github.lcsc-kicad.browser`，版本为 `0.4.0`。升级时使用同一标识的新版安装包。

如果曾安装本项目的第一版「立创浏览器」，可先在 PCM 中卸载该旧包，再安装「立创元件桥」，以免两个入口同时出现。已经导入工程的 `lcsc/` 目录及工程库表保留在原工程中。

## 从商品页导入

1. 打开并保存 `.kicad_pro` 工程和当前编辑的文件。
2. 从原理图或 PCB 编辑器工具栏打开「立创元件桥」。
3. 确认顶栏中的工程名称。点击工程名称或「选择工程」指定目标 `.kicad_pro` 文件，悬停可查看完整路径。
4. 在内置浏览器中搜索商品。
5. 点击该行「加入购物车」右侧的 **「导入」**，或进入详情页点击右下角的 **「导入 KiCad」**。程序读取所选元件的料号，后台下载、转换并登记工程库。
6. 顶栏显示导入状态。点击状态或右侧「导入记录」图标可查看器件、资源和记录；完成后在 KiCad 工程库 `LCSC` 中按料号搜索，例如 `C2040`。

页面按钮是导入入口。浏览、搜索和切换商品页不会直接下载或修改工程。若该商品没有可用的 EasyEDA 设计数据，窗口会报告下载失败的原因。

## 界面布局

- **顶栏**：后退、前进、刷新、首页、地址输入和工程选择。输入料号打开中文商城搜索，也可粘贴商品链接。
- **商城**：默认占满顶栏下方的浏览区域。
- **网页导入按钮**：列表页位于每个可识别自营商品的「加入购物车」右侧；详情页位于右下角。按钮显示导入中、已导入或重试。
- **导入记录**：右侧面板默认隐藏，点击顶栏图标展开，失败时自动显示错误详情。

界面基于本地打包的 Bootstrap 5.3.3，采用灰白与蓝色的平面风格。界面资源不需要网络或 CDN；商城浏览与器件下载仍需要网络连接。按钮提供键盘焦点，动画遵循系统的减少动态效果设置。

KiCad 10.0.6 的原理图 API 只返回原理图文件名。插件会结合 KiCad 启动时传入的 `KIPRJMOD` 工程目录，确认工程文件和对应原理图均存在后使用该目录；无法确认时，请选择对应的 `.kicad_pro` 文件。

首次新增库后，已打开的编辑器可能仍缓存旧库表。若库列表尚未出现新库，保存工作并重新打开该工程的编辑器。

## 工程文件

不同料号保存在同一个工程库中：

```text
你的工程/
├── 你的工程.kicad_pro
├── sym-lib-table
├── fp-lib-table
└── LCSC/
    ├── LCSC.kicad_sym
    ├── LCSC.pretty/
    │   ├── C2040_<封装名>.kicad_mod
    │   └── C其他料号_<封装名>.kicad_mod
    └── LCSC.3dshapes/
```

插件在当前工程的 `sym-lib-table` 和 `fp-lib-table` 中各登记一个 `LCSC` 库。路径使用 `${KIPRJMOD}`，把 `LCSC/` 和库表与工程一并保存，即可保留相对引用。符号、封装和模型名称加上料号前缀，避免不同器件重名。

重复导入已经完成的同一器件会保留已有文件。若上次未能下载到任何可用的 3D 模型，再次点击导入会尝试补齐；确认没有模型的器件不会反复下载。补齐时保留已有符号和封装几何，封装被手动修改时会提示冲突。3D 模型缺失不影响符号和封装使用；最终结果以导入提示为准。

若导入进程异常退出，下次导入会先恢复未完成的文件更新，再继续处理。若中断后相关文件又被手动修改，插件会保留恢复资料并提示处理，不会覆盖这些修改。遇到同名文件或库表冲突时，也不会静默覆盖已有内容。

升级后再次点击旧版已完整导入的器件，会优先从本机复制到共享 `LCSC` 库，无需重新下载。旧版 `lcsc/C料号` 文件及 `LCSC_C料号` 库项保留，确保已经放置的符号和封装仍能找到原引用。Windows 下旧 `lcsc` 与新 `LCSC` 为同一目录，可能沿用原有小写目录显示。

## 下载速度

符号与封装共用一份设计数据；获取后，OBJ 和 STEP 模型同时获取。对于支持范围请求且可校验文件版本的较大 STEP，最多使用 4 个线程分段下载，检查区间和完整性后合并；不支持时使用普通下载。侧栏显示下载与保存阶段，展开「活动记录」可以查看各请求耗时。实际速度仍受网络与数据源响应影响。

下载数据在本机缓存：器件数据保留 24 小时，模型保留 30 天，总容量最多 256 MB。Windows 默认缓存位于 `%LOCALAPPDATA%\LCSCKiCadBridge\cache\v1`。同一元件导入另一个工程时可复用缓存，生成的 KiCad 库仍单独保存在各自工程内。缓存不可用时照常联网下载；如需重新获取最新数据，可在关闭插件后清除此缓存目录。

## 常见问题

**原理图工具栏没有入口**

确认使用 KiCad 10.0+、已安装 `0.2.0` 或更新的独立安装包，并且启用了插件 API。重开编辑器后等待插件环境初始化完成；必要时使用「工具 → 刷新插件」。原理图入口通过 IPC 插件机制加载。

**窗口无法创建或网页空白**

Windows 先检查插件解释器是否指向 KiCad 自带的 `bin/pythonw.exe`，以及是否有可用的 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。网页加载还受网络连接、登录状态和商城访问限制影响。

从 `0.3.1` 起，插件启动时的 Python 异常会显示「启动失败」提示，并保存本地错误记录。Windows 默认位置为 `%LOCALAPPDATA%\LCSCKiCadBridge\logs\launch-error.log`，无法写入时尝试临时目录；以错误提示中的实际路径为准。此日志不上传，API 连接令牌会脱敏。若尚未出现工具栏按钮，说明仍应检查 KiCad 插件发现及环境初始化，启动器的错误日志此时可能尚未生成。

**商品页没有「导入 KiCad」按钮**

确认已经打开立创商品详情页并等待商品信息完成加载，必要时刷新页面。只有同页的商品数据已确认后才会插入按钮；搜索页、验证页和商品数据无法确认的页面不会插入按钮。商城页面结构发生变化时，页面按钮适配可能需要更新。

**页面出现「安全检测」或人工验证**

这类提示可能由商城的访问验证触发。`0.3.2` 修正了网页子框架误拦截：正常 HTTP/HTTPS 子页面交给浏览器加载，导入仍只接受当前立创商品。按钮在商品数据确认后才插入，重复检查复用已有控件，不再每秒完整重建。内置浏览器沿用原有持久会话目录，不清理 Cookie。

需要滑块、验证码或登录时，请在页面中手动完成。插件不自动完成验证，也不能保证网站永远不要求验证。若验证后仍反复出现，请提供出现位置、提示文字和商品链接；避免反复刷新。遇到证书或系统安全告警时，先确认告警原因，不要直接关闭保护。

**按钮显示错误或下载失败**

查看左侧导入结果提示，展开「活动记录」获取详情。确认目标工程已保存且可以写入，并检查网络连接。并非所有立创商品都有可下载的设计数据。

**如何使用导入的符号**

在原理图编辑器中放置符号时，选择 `LCSC` 工程库，再按料号搜索。符号关联 `LCSC` 库中的对应封装。正式设计前，应根据数据手册核对引脚和封装尺寸。

## 从源码构建

构建需要 Python 3.10+。在仓库根目录运行：

```powershell
git submodule update --init --recursive
python tools/build_lcsc_plugin.py
```

也可使用 `py -3 tools/build_lcsc_plugin.py`。默认输出为 `dist/LCSC-KiCad-Bridge.zip`；用 `--output 路径.zip` 可更改输出位置。

构建过程使用仓库当前锁定的转换器源码，不修改元数据和子模块，不安装到本机 KiCad。安装包只包含立创元件桥运行文件、本地界面资源、转换器、说明及许可证，排除开发文件、缓存、日志和本地配置。构建脚本检查界面 HTML、CSS、JavaScript、Bootstrap 样式及其 MIT 许可证是否齐全。

在仓库根目录运行 `python -m unittest discover -s tests -v` 可执行自动化检查；界面测试需要可用的 wxPython 环境。实际验证还应从原理图和 PCB 工具栏分别启动，使用测试工程点击网页按钮，并检查生成的符号、封装和模型。

`tools/smoke_lcsc_browser.py` 可在 KiCad Python 环境下检查实际商品页按钮、下载和重复导入，测试使用临时工程。`plugins/lcsc_launch.py --check` 可在插件使用的 Python 环境中检查运行依赖；此检查不打开编辑器，也不证明工具栏入口已成功加载。

**0.3.0 验证结果**：在 Windows 的 KiCad 10.0.6 Python/WebView2 环境中，82 项自动化检查和 8 组离线原生界面检查通过。实机检查覆盖本地框架加载、导航及工程按钮消息、地址输入保护、长路径、导入中/完成/失败状态、活动记录和 1060×700 最小窗口布局。

真实商品页测试通过页面内按钮下载 C2040 的符号、封装、STEP/WRL 模型，并登记工程库；只浏览页面不会导入，重复点击保留已有器件。运行 `python tools/smoke_lcsc_ui.py` 可执行离线原生界面检查；加 `--hold` 会保留通过后的窗口供视觉检查。

**0.3.2 验证结果**：110 项自动化检查通过，包括子框架不影响主页面状态、非商品页不插入节点、按钮复用和页面切换期间的导入校验。C2040 的实际网页按钮下载、工程库登记及重复导入再次通过。测试期间未复现用户报告的安全检测，因此这些结果确认兼容性修复和导入功能，不代表网站不会再次要求验证。

**0.4.0 实测**：在 KiCad 10.0.6 中，C2040 与 C1002 已合并到同一个 `LCSC` 库，两个符号和两个封装均通过 KiCad CLI 读取并导出，封装及 3D 引用对应文件存在。实际商品页按钮导入、重复点击和 8 组原生界面检查通过。C2040 使用独立空缓存下载时，STEP 分段下载约 14.5 秒，整个导入约 20.2 秒；已有完整缓存时，导入新工程约 0.3 秒，同工程重复点击约 0.02 秒。以上为本机单次测量，实际耗时随网络和器件变化。
